# Sprint 1

## Sprint Goal

Develop the user authentication module for the AI-Powered Personalized Practice Portal for JEE Mathematics.

## Sprint Duration

23/06/2026 - 28/06/2026

---

## User Stories

### US-1: User Registration

**As a student**, I want to create an account so that I can access the platform and save my future progress.

### US-2: User Login

**As a registered student**, I want to log in using my credentials so that I can securely access my account.

### US-3: User Authentication

**As a system user**, I want my credentials to be verified so that only authorized users can access protected resources.

---

- Registration Page
- Login Page
- Authentication Backend
- MongoDB User Database

## Success Criteria

- Users can successfully register.
- Users can log in using valid credentials.
- Invalid login attempts are rejected.
- User information is stored in MongoDB.
- Authenticated users can access protected pages.
- Users can securely log out.

---

## Expected Outcome

A student should be able to:

- Create an account
- Log in securely
- Access authenticated pages
- Log out successfully
