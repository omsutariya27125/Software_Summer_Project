# Sprint 3

### Sprint Goal
Deploy the base web application and backend API with bug fixes, implement chapter-wise question solving, develop the user profile module with academic goals, and create the basic Quiz page UI.

### Sprint Duration

10/07/2026 - 15/07/2026

---

## User Stories

### US-11: Secure Logout

As a logged-in student, I want to log out securely so that unauthorized users cannot access my account.

### US-12: Chapter-wise Question Practice

As a student, I want to practice questions from selected chapters so that I can improve my understanding of Mathematics concepts.

### US-13: Instant Answer Evaluation

As a student, I want my answers to be evaluated immediately so that I can know whether my answers are correct.

### US-14: View Solutions and Explanations

As a student, I want to view the correct answers and explanations so that I can learn from my mistakes.

### US-15: Manage Profile

As a student, I want to view and edit my profile so that I can keep my personal details up to date.

### US-16: Manage Academic Goals

As a student, I want to view and edit my academic goals so that I can receive more personalized question and topic recommendations.

### US-17: Chapter-wise Quiz

As a student, I want to take quizzes based on selected chapters so that I can evaluate my preparation.
